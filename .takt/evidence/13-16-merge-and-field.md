# Шаги 13 и 16 — Слияние и проверка в бою

## Шаг 13 — Слияние

Целевая ветка из постановки (`fix/broker-flow-integrity`) к моменту слияния была мертва: целиком влита в `master` и отставала от него. Слияние выполнено в `master` — настоящую цель, а не названную три дня назад.

**Объединённый кандидат собирался и проверялся отдельно, до вливания.** Это не формальность: он нашёл дефект, которого нет ни в одной из сливаемых сторон.

```
git rev-list --count master..integ/concierge-turnstate  → 18   (впереди)
git rev-list --count integ/concierge-turnstate..master  → 0    (позади)
git merge --ff-only integ/concierge-turnstate           → быстрая перемотка
git status --porcelain                                   → (пусто)
```

**Дефект, найденный только сборкой кандидата.** Ключ `inFlight` оказался объявлен дважды в одном объектном литерале `WS.engine`: этой веткой — потредово, с сеттером для тестов; мастером — геттером над внутренним флагом. Git свёл обе стороны без конфликта, они лежат в разных участках файла, а в JavaScript при двух одинаковых ключах побеждает последний. Потредовый сеттер оказался затёрт, занятость стала вечным `false`, и разом отвалились защита от двойной отправки, отмена и сторож — 10 красных проверок.
`[проверено прогоном: `node src/test/smoke.js`]` → до правки `checks: 2049 passed: 2039 FAILED: 10`, после `checks: 2049 passed: 2049 FAILED: 0`.

Обе стороны чинили один дефект последовательно: мастер убрал мёртвый литерал `inFlight: false`, из-за которого защита не срабатывала ни разу с момента написания; эта ветка следом сделала занятость потредовой. Более грубая версия удалена, её объяснение сохранено комментарием — причина «не возвращать сюда литерал» ценнее удалённой строки.

**Работа мастера проверена на выживание мутацией, а не чтением.**
`[проверено прогоном: `npm run mutation`]` → `Поймано 14 из 14`, включая `офлайновый ответ помечен на экране` — тот самый признак происхождения ответа, который мастер ввёл в середине этого прогона и который эта ветка могла бы откатить, правя `live.js` и `engine.js`.

Один якорь не сошёлся (`офлайн не отрицает существующий объект :: якорь найден 0 раз`). Проверено — не наш: якорь указывает на `src/js/agent.js`, который эта ветка не трогала вовсе, и его текст отсутствует в самом мастере.
`[проверено прогоном: `git diff --name-only master..HEAD -- src/js/agent.js`]` → пусто. Находка о мутационной оснастке параллельной сессии: она честно печатает «НЕ ПРОВЕРЕНО», но возвращает нулевой код, поэтому автоматика по коду возврата увидит зелёное.

**Собранный файл пересобран отдельным коммитом.** `index.html` — это то, что отдаётся людям; в кандидате он отставал от слитых исходников на 22 КБ. Влить исходники и не пересобрать — значит положить работу так, чтобы её никто не увидел.
