# Компоновка карточек WESPACE — стандарт

Статус: действует с 15 августа 2026. Проверяется тестами в `src/test/smoke.js` (блоки «одна грамматика карточки», «стилевой файл разбирается»).

Правила ниже описывают **не то, как карточки выглядят, а то, что решает, какой блок где стоит**. До этого стандарта каждая карточка писала свою раскладку руками: где-то `dx-grid2`, где-то `deal-top`, где-то `<div style="margin-top:14px">`; одна карточка ставила ленту событий рядом с пятистрочным блоком, другая держала кнопки действий внутри вкладки. Одни и те же данные — шесть разных грамматик; отсюда и ощущение, что «каждый раз получается криво».

## 1. Одна анатомия страницы сущности

Порядок сборки один для сделки, клиента, компании, заявки, договора и объекта. Его задаёт `entityBody(spec)` — карточка не собирает шапку сама:

```
шапка страницы     ← [назад · куда] и действия страницы (открыть клиента, чат)
обложка            spec.hero    — фото, имя/название, ключевые факты, статус-чипы
быстрые действия   spec.acts    — панель глаголов, всегда здесь
состояние          spec.state   — «что сейчас»: линия стадий, чипы, пара фасадных блоков
вкладки            spec.tabs
тело вкладки       spec.render(tab)
консьерж           spec.concierge
```

**Быстрые действия — над вкладками, не внутри них.** Раньше на клиенте и компании панель жила внутри вкладки «Обзор»: переход на «Историю» оставлял экран без единого глагола. На сделке и договоре она стояла посреди шапки, на заявке её не было вовсе. Место у панели одно, и оно не зависит ни от сущности, ни от вкладки — это и есть ответ на вопрос «где кнопки».

## 2. Ряды тела карточки — один конструктор

Тело карточки собирается `cxStack([...])`. Элемент массива — ряд:

- строка — ряд во всю ширину;
- массив из двух — ряд из двух блоков; если один пуст, ряд становится полноширинным;
- `cxCol([...])` — колонка блоков, когда половину ряда занимает не один блок, а стопка.

Никаких `<div style="margin-top:14px">` между блоками: ритм задаёт `--card-gap`, один шаг между рядами и внутри колонок. Отступ карточки — свойство карточки, а не того, кто последним правил блок.

## 3. Что можно ставить в пару, а что нельзя

Ряд из двух колонок высок ровно настолько, насколько высок больший блок. Поэтому:

- **в пару — только блоки, чья высота ограничена полями:** справка, реквизиты, параметры, портрет, сигналы, карточка клиента;
- **во всю ширину — всё, что растёт вместе с записью:** лента событий, история, список документов, список объектов подбора, вехи договора.

Лента, поставленная рядом с пятистрочным блоком, растягивает соседа на свою высоту — это и есть «дырявое одеяло». Спарить блок в две строки со списком на двадцать нельзя никаким выравниванием.

## 4. Именование

Один смысл — один заголовок на карточке. Два блока с названием «Профиль предпочтений» (объявленные параметры и наблюдённое «выбрал / отклонил») сведены в один: наблюдения — под чертой внутри объявленного профиля.

Факт, показанный в обложке, не повторяется блоком ниже: канал связи, KYC и язык живут в обложке, а «Контактные данные» держат только номера.

## 5. Чем это проверяется

| Правило | Проверка |
|---|---|
| Панель действий выше вкладок и вне тела вкладки, на всех пяти сущностях | `<сущность> · панель действий выше вкладок / вне тела вкладки` |
| Панель не исчезает при смене вкладки | `· панель действий пережила смену вкладки` |
| Лента не стоит в паре | `· лента не стоит в паре с другим блоком` |
| Ряды не носят собственных отступов | `· ряды не носят собственных отступов` |
| Лента клиента — последний блок, во всю ширину | `client · лента событий — последний блок` |
| Один «Профиль предпочтений» | `client · «Профиль предпочтений» на карточке один` |
| Стилевые файлы разбираются (скобки сходятся) | `css · <файл> — скобки сходятся` |
| Классы конструктора описаны в стилях | `css · .cx-stack описан` и далее |

Дополнительно — внешний обмер: `node C:/temp/ws-audit-layout.js index.html <ширина>` печатает по каждой карточке ряды, высоты блоков и разницу между высотой блока и высотой его содержимого. Разница больше 40 px помечается как «пусто» — это и есть дыра в сетке.

## 6. Что осталось за рамками

- Карточка объекта пока без вкладок: всё тело идёт одним столбцом рядов. Анатомия та же, вкладок нет — блоков мало.
- Модальные карточки (задача) используют ту же сборку, но без обложки и состояния.
